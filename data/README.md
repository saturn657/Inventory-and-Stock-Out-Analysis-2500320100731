# StockWise data

The initial project dataset is synthetic teaching data generated by
`src/01_generate_data.py` with a fixed random seed (42). It does not represent
a real retailer or supplier.

From the repository root, install dependencies and generate the raw CSV files:

```bash
python -m pip install -r requirements.txt
python src/01_generate_data.py
```

The generator writes these files to `data/raw/`:

- `products.csv`
- `suppliers.csv`
- `inventory.csv`
- `purchase_orders.csv`
- `stock_movements.csv`

It intentionally adds a small number of duplicate rows, missing values,
invalid values, and inconsistent text labels. These are controlled examples
for the data-cleaning stage. Do not use raw files as final analysis inputs;
run the cleaning script in the next pipeline stage first.

The generator uses a fixed reference date of 2026-11-25 so that repeated
runs remain deterministic. Update that date deliberately if a new dataset
version is required, and document the change.
