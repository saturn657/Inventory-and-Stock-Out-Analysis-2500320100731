# StockWise — Inventory and Stock-Out Analysis

A reproducible inventory analytics project built with Python, Pandas, Oracle SQL/PLSQL, Excel, Streamlit, and Power BI.

> **Dataset notice:** StockWise uses synthetic teaching data generated with a fixed random seed. The records do not describe a real retailer, supplier, or inventory system.

## 1. Problem

Retail and distribution businesses need enough stock to meet demand without holding unnecessary inventory. StockWise brings product, supplier, inventory, purchase-order, and stock-movement records into one analysis workflow to identify stock-outs, low-stock products, inventory value, and supplier delivery delays.

## 2. Project objectives

- Generate and clean reproducible inventory-related data with a documented quality log.
- Calculate available stock, low-stock and stock-out counts, and inventory value.
- Analyse supplier lead times and delayed deliveries.
- Build Python charts, an interactive Streamlit dashboard, Oracle SQL/PLSQL reports, and Excel/Power BI reporting assets.
- Validate data quality and reconcile Python results with Oracle query outputs when Oracle is available.

## 5. Run the project in five steps

### Step 1 — Clone the repository

```bash
git clone https://github.com/saturn657/Inventory-and-Stock-Out-Analysis-2500320100731.git
cd Inventory-and-Stock-Out-Analysis-2500320100731
```

### Step 2 — Create and activate a virtual environment

Windows PowerShell:
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

macOS/Linux:
```bash
python -m venv .venv
source .venv/bin/activate
```

### Step 3 — Install Python dependencies

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### Step 4 — Generate and clean the data

```bash
python src/01_generate_data.py
python src/02_clean_data.py
```

Raw CSVs are written to `data/raw/`; cleaned CSVs are written to `data/clean/`. The raw files are never overwritten. Cleaning decisions and affected-row counts are recorded in `reports/cleaning_log.csv`.

### Step 5 — Launch the dashboard

```bash
streamlit run app/streamlit_app.py
```

The dashboard provides four KPI tiles, category/supplier/date filters, three interactive Plotly charts, and a reorder-attention table.

## 7. Oracle SQL and PL/SQL

1. Configure an Oracle Database schema and run `sql/schema.sql`.
2. Set `STOCKWISE_ORACLE_USER`, `STOCKWISE_ORACLE_PASSWORD`, and `STOCKWISE_ORACLE_DSN` as environment variables.
3. Run `python src/03_load_sql.py --replace` to load the clean CSVs and export the seven SQL reports to `reports/sql_results/`.
4. Use `python src/03_load_sql.py --skip-load` to rerun reports against already-loaded tables.

The `--replace` option deletes the existing StockWise fact and dimension rows before reloading; use it only in the dedicated project schema. Do not commit database credentials.

**Database status:** Oracle query execution and Python-versus-Oracle reconciliation are pending a configured Oracle instance. The test report marks this check SKIP/PENDING rather than inventing SQL results.

## 8. Business rules and assumptions

- Stock-out: available quantity <= 0.
- Low stock: 0 < available quantity <= reorder level.
- Inventory value: available quantity × unit cost.
- Supplier lead time: actual delivery date − order date, in calendar days.
- Delayed delivery: actual delivery date > expected delivery date.
- The generated inventory table contains one snapshot date; it does not provide historical daily stock snapshots.
- The estimated stock-out trend in the Python charts reconstructs daily balances from opening stock and movements. It is an estimate, not observed daily inventory.
- The initial data is synthetic; results should not be used for operational decisions.

## 9. AI / ML disclosure

No AI or machine-learning model is used for forecasting, classification, or recommendations. Synthetic data is generated using deterministic Python random-number generation with a fixed seed. The analysis uses documented business rules, Pandas, SQL, formulas, and visualisations. No external AI API is required by the project.
